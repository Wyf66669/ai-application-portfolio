# 教务管理系统 · AI 作业 / 考试发布与批改

> 毕业设计课题，已通过学校答辩。面向 AI 应用工程岗位的核心展示项目。

## 1. 项目定位

前后端分离的教务管理平台，覆盖选课、排课、成绩、考勤、请假、作业考试等业务。  
本项目的差异化能力：**把 LLM 做成业务功能**，而不是仅用于写代码提效。

## 2. 技术栈

| 层 | 技术 |
|----|------|
| 后端 | Spring Boot、Spring MVC、MyBatis、JWT |
| 数据库 | MySQL；Redis 缓存（不可用时降级内存缓存） |
| 前端 | Vue 3、HTML5、Axios、Element Plus / Bootstrap |
| AI | DeepSeek API（RestTemplate 调用） |
| 构建部署 | Maven、内嵌 Tomcat；了解 Nginx 反向代理 |

## 3. AI 能力说明

### 3.1 AI 作业 / 考试发布

教师选择课程、输入关键词或难度后，调用试卷生成服务按题型模板（选择 / 填空 / 计算 / 概念）生成试卷与参考答案，确认后发布；考试可走管理员审批后再对学生可见。

### 3.2 AI 作业 / 考试批改

学生提交后：

- **客观题**：程序规则判分  
- **主观题**：调用 DeepSeek 评分并生成评语  
- **概念题**：先从课本知识库检索相关片段，再拼入 Prompt（轻量 RAG），减少幻觉  

批改结果写回成绩并推送通知；API 异常时有本地降级逻辑。

### 3.3 RAG 流程（当前实现）

```text
题干 / 章节引用
   ↓
MySQL 课本表按关键词 / 章节检索片段
   ↓
Prompt = 题目 + 标准答案 + 课本原文 + 学生作答
   ↓
DeepSeek 返回分数与评语
```

后续可迁移到 **Dify 知识库 + Workflow API**，由 Java 后端通过 HTTP 调用，语义检索更强。
